# Requirement — User Management

Administrators can browse, search, filter, add, edit and delete users.

## Business rules provided

- Users can be searched by keyword.
- Users can be filtered by status.
- The list is paginated.
- Deleting a user requires confirmation.

## Not provided (must not be invented)

- Page size used by the product (the example component hard-codes 10 for the demo)
- Which fields the search matches
- Whether search is case-sensitive
- The full list of allowed status values
- Delete / edit permission rules
- Default sort order
- Email uniqueness constraint
