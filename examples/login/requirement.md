# Requirement — Login

Users can sign in using a registered email and password.

## Business rules provided

- Email is required.
- Password is required.
- Password length is 8-20 characters.
- A "Remember me" option is available.
- A "Forgot password?" link is available.

## Not provided (must not be invented)

- Failed-attempt / account-lock policy
- Session or token duration
- Password complexity requirements
- Post-login destination
- Exact invalid-credential message
